# Medistar

Medistar é uma aplicação web criada para a Global Solution, simulando uma camada inteligente de dados espaciais para apoiar a telemedicina em regiões isoladas.

## Objetivo

A solução combina dados clínicos, localização geográfica, conectividade via satélite, riscos climáticos e barreiras de acesso para apoiar a priorização de atendimentos médicos remotos.

## Tecnologias

- React
- TypeScript
- Vite
- Azure App Service
- GitHub Actions
- Azure Key Vault
- Application Insights

## Como executar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Contexto espacial

A solução se conecta à Indústria Espacial por meio do uso simulado de conectividade via satélite, dados geoespaciais e sensoriamento remoto para melhorar decisões em telemedicina em regiões isoladas.
